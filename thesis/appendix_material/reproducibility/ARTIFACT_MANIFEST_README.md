# Artifact manifests

`artifact_manifest.tsv` lists every piece of evidence behind the reported tables, with a portable destination, size, SHA-256 (for files; not for directories or checkpoints), status (`tracked`, `external`, `external-optional`, `withheld`, `regenerable`), the table or result it is needed for, and the script or command that produced it. `artifact_manifest_external.tsv` lists the minimum external archive: the 40 PersistBench-derived files that `export_scripts/compute_tables.py` reads. Both contain no usernames and no absolute paths. They are generated by `thesis/scripts/validation/build_artifact_manifests.py` from the original cluster working tree.

Logical roots in the portable destinations:

| Root | Meaning |
|---|---|
| `REPOSITORY_ROOT` | a clone of this repository |
| `PERSISTBENCH_ARTIFACT_ROOT` | the extracted external archive (contains `outputs/` and `outputs_gemma3_judge/`) |
| `MUSE_EVAL_STORAGE` | optional per-example `MUSE_EVAL.json` files (not needed for any table) |
| `CHECKPOINT_STORAGE` | model checkpoints (never in Git; provenance only) |
| `HIDDEN_STATE_STORAGE` | hidden-state tensors and bulk mechanistic outputs (regenerable) |

## Status: not published

The external archive (40 files, 77,198,596 bytes) has **not** been created or uploaded, and publication is **blocked**: every file in it is derived from PersistBench prompts and `external/PersistBench` has no licence file at the pinned commit. Until the PersistBench authors clarify redistribution, a clean clone can verify the code, manifests and tracked evidence but cannot regenerate the tables.

## Regenerating the tables once the archive exists

```bash
# 1. extract the archive so that $ROOT/outputs/ and $ROOT/outputs_gemma3_judge/ exist
ROOT=$HOME/persistbench_artifacts
# 2. verify the files against the manifest (prints nothing and exits 0 if all match)
awk -F'\t' 'NR>1{print $4"  "$1}' thesis/appendix_material/reproducibility/artifact_manifest_external.tsv | (cd "$ROOT" && sha256sum -c --quiet)
# 3. check that all 46 inputs of compute_tables.py are present
python3 thesis/appendix_material/reproducibility/export_scripts/compute_tables.py --check-inputs --artifact-root "$ROOT"
# 4. regenerate into a scratch directory and compare with the tracked tables
python3 thesis/appendix_material/reproducibility/export_scripts/compute_tables.py --artifact-root "$ROOT" /tmp/regenerated_tables
for f in /tmp/regenerated_tables/*.tsv; do cmp "$f" "thesis/appendix_material/tables/$(basename "$f")"; done
```

`--artifact-root` can also be set with the environment variable `PERSISTBENCH_ARTIFACT_ROOT`. It replaces `external/PersistBench/` for the PersistBench inputs; nothing is copied into the submodule, and no input is taken from anywhere else when it is given. On 2026-10-18 this procedure, run in a clean copy of the repository with the 40 files supplied through a temporary root, reproduced all five tracked tables byte for byte.
